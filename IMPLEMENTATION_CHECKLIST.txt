WHAT I MUST CODE BY HAND VS. WHAT CODEX CAN HELP WITH LATER
===========================================================

Code by hand to learn:
- ReviewState semantics, schema fields, prompts, and model behavior.
- URL/API handling, diff boundaries, finding validation, retry conditions,
  graph edges, and investigation limits.
- How evidence supports findings and how tests prove that behavior.

Codex can help later with:

  out edge cases.
- Suggesting focused tests, diagnosing failures, and reviewing a change you
  have already attempted.
- Scaffolding repetitive non-domain code when you explicitly ask.

PITFALLS TO WATCH FOR
=====================

- Hallucinated line numbers: verify references against changed-file diff data.
- Prompt injection in diffs: treat repository content as untrusted input.
- Huge pull requests: cap files and total context, and report explicit skips.
- Rate limits: handle responses and backoff deliberately; bound retries.
- Malformed JSON: distinguish invalid output from an actual code bug.
- Infinite agent loops: cap review retries and tool calls with explicit stops.
- Exposing tokens: never log credentials or commit local .env files.
